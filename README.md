# (Mis)Pronunciation Detection for L2 English Speakers 

Este trabalho aborda o desafio da (i) detecção automática de erros de pronúncia em falantes de inglês como segunda língua (L2). O (ii) objetivo é desenvolver um sistema que identifique desvios fonéticos ao comparar a fala do usuário com o padrão esperado. A questão de pesquisa foca em quão precisamente um modelo de reconhecimento de fonemas pode isolar erros específicos de falantes não nativos. Para isso, será utilizado o modelo wav2vec 2.0 para a extração da sequência de fonemas do áudio de entrada. Paralelamente, a ferramenta Whisper (OpenAI) converterá o áudio em texto, que será processado por um algoritmo de Grapheme-to-Phoneme (G2P) para gerar a transcrição fonética alvo. A detecção de erros ocorrerá através do alinhamento e comparação entre essas duas sequências. O (iii) conjunto de dados utilizado será o L2-ARCTIC, um corpus de fala não nativa que contém anotações detalhadas de erros de pronúncia, permitindo a validação da acurácia do modelo proposto.
